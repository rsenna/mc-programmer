Zero means each step represents an 8th note. One

Each pair of bytes contains a MIDI note number

At the offset of 0x40 hexadecimal, we can see
the starting points of each note within a step.
The starting points are expressed in the hundreds
of a step time and they are encoded using pairs
of bytes. Again, in each byte of a pair, only
four bits are used. And there is more. Since the
nodes can start before a step starts, the start
time can be negative and the negative start time
values are encoded in two complement encoding.
So for example 0 will be 0x00 hexadecimal but
-1 will be 0xFF hexadecimal. -2 will be 0xFE
hexadecimal - and so on down to -50 which
encodes to 0xCE hexadecimal. The ending times of
the notes are at the offset of 0x60 hexadecimal
in each step. They can have the values from 0
to 100 or 0x64 hexadecimal. The default values
are 0x50 hexadecimal which is 80 decimal. But
there is a catch. If a node is longer and it
ties to the next step, the end time must be set
to 100 and only then the note may be continued in
the next step. If the end time is set to a smaller
value of up to 99, the note ends in the particular
step after the number of cents expressed in
this field. The last field in the note step
is the information about the "substep". If this
field is zero, then there is no "substep" and
the note is played once per step. But you can set
it to two notes per step, three, four, or "flam".

keep this video relatively short. The motion
sequencing in MC grooveboxes is much simpler
than the note sequencing. The motion sequencer
starts at the offset of 0x40000 hexadecimal in
each clip. You probably know that you can record
and edit the four knobs C1 to C4. But there is
more. You can also record the parameters like
sustain pedal operation, aftertouch, modulation
and many many more. And those parameters are also
recorded independently from the C1 to C4 knobs. I
tested recording of two additional parameters,
but the MC's can record up to four different
sources plus the pitchbend wheel separately.
I didn't check that feature on MV-1 though.
In the main motion sequencer, the address
is divided in a similar manner as in the
note sequencer, but this time we start at
the offset of 0x40000 hexadecimal in each
clip. The steps are encoded like this
and the least significant bite contains
the offset of the motion lanes. So this way
each step can contain up to 8 motion lanes.
The lowest 4 offsets are assigned to the
C1 to C4 knobs and the latter 4 are for
recording other parameters live. For example,
touch, modwheel, sustain, and so on. Each step
is divided into 8 substeps so that the motion
can change with a better time resolution than
just a single step time. If you program motion
live or if you use the motion automation tool,
the sequencer will use all the substeps to record
and play the motion. But if you program motion
using the step sequencer, the motion can
be set only with the whole step resolution.
